# 결정사항

기획서(v0.1)를 쓰면서 가정한 것들이다. 답이 없으면 "추천 기본값"으로 진행한다. 바꾸고 싶은 항목만 알려 주면 된다.

## 지금 정하면 좋은 것

| 번호 | 항목 | 선택지 | 추천 기본값 | 이유 |
|---|---|---|---|---|
| 1 | 최종 목표 | (가) 노래 반주(코드 + 스트로크) / (나) 멜로디·핑거스타일 연주 / (다) 둘 다 | (가) 노래 반주 | 통기타 입문자 대부분의 목표이고, 커리큘럼 5~8단계가 이 방향이다. (나)를 고르면 2단계와 9단계 비중을 늘린다 |
| 2 | 먼저 쓸 기기 | (가) PC·노트북 / (나) 휴대폰 / (다) 태블릿 | (가) PC·노트북 | 개발과 시험이 가장 빠르고 HTTPS 호스팅 없이 된다. 휴대폰은 1단계가 끝난 뒤 붙인다 |
| 3 | 기타 종류 | (가) 통기타(쇠줄) / (나) 클래식 기타(나일론 줄) / (다) 아직 없음 | (가) 통기타 | 튜닝과 음은 같아서 앱은 둘 다 된다. 설명 글과 그림만 달라진다 |
| 4 | 하루 연습 시간 | 10분 / 15분 / 30분 | 15분 | 매일 짧게 하는 쪽이 낫다는 자료가 많다. "오늘의 연습" 길이를 여기에 맞춘다 |

## 나중에 정해도 되는 것

| 번호 | 항목 | 선택지 | 추천 기본값 | 정할 시점 |
|---|---|---|---|---|
| 5 | 앱 이름 | 여섯줄 / 기타 첫걸음 / 딩가딩가 / 직접 정하기 | 여섯줄 | 2단계 전 |
| 6 | 휴대폰에서 쓰는 방법(HTTPS 주소) | (가) 레포를 공개로 바꾸고 GitHub Pages / (나) 레포는 비공개로 두고 외부 무료 호스팅(Cloudflare Pages, Vercel 등) 연결 | 그때 비교해서 제안 | 1단계 끝. GitHub 무료 계정은 비공개 레포에서 Pages를 쓸 수 없다. (나)는 요금과 접근 제한 조건을 그때 확인한다 |
| 7 | 코드 판정 넣는 시점 | 4단계 / 더 앞당기기 | 4단계 | 단음 판정이 실제 기타에서 안정된 뒤 |
| 8 | 수록 곡 | 기획서 11장 후보 | 후보 그대로 | 3단계. 곡마다 저작권 다시 확인 |
| 9 | 아이들 모드 | 넣는다 / 안 넣는다 | 5단계 이후 프로필 분리만 | 5단계 |
| 10 | 점수 표현 | 별 3개 / 퍼센트 / 둘 다 | 별 3개 + 정확도 작게 | 2단계 |

## 본인 확인이 필요한 것(내가 대신 못 하는 것)

- 1단계가 끝나면 실제 기타로 튜너를 써 보고, 녹음 도우미로 줄 6개 소리를 녹음해 주어야 한다. 이 녹음이 판정 엔진의 시험 자료가 된다.
- 레포 공개 전환, 외부 호스팅 연결은 승인 뒤에만 한다.
