# guitar-lesson

초급자를 위한 기타 레슨 웹앱. 마이크 앞에서 치면 맞았는지 바로 알려 주는 무료 한국어 연습 앱을 목표로 한다.

## 지금 상태
- 0단계 기획 완료 (2026-11-12). 앱 코드는 아직 없다.
- 다음: 1단계 소리 엔진과 튜너.

## 문서
- [docs/기획서.md](docs/기획서.md): 목표, 참고 앱 분석, 기술 타당성, 커리큘럼, 기능, 판정 설계, 화면, 진행 단계
- [docs/결정사항.md](docs/결정사항.md): 정해야 할 것과 추천 기본값

## 타당성 실험
```
node spike/feasibility.mjs
```
합성한 기타 소리로 단음 피치 검출과 코드 확인이 되는지 본 실험이다. 결과 요약은 기획서 3장에 있다.

## 진행 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 기획 | 완료 |
| 1 | 소리 엔진과 튜너 | 대기 |
| 2 | 단음 판정 연습 | 대기 |
| 3 | 흘러가는 TAB | 대기 |
| 4 | 코드 | 대기 |
| 5 | 완성(레슨 채우기, 곡, 기록, 휴대폰 배포) | 대기 |
